========================================================================
EASIEST WAY (1-CLICK / 1-COMMAND)
========================================================================

Just run ONE command from this directory:

    .\run.bat

(Or literally double-click "run.bat" in File Explorer!)

Alternatively in PowerShell:
    .\run.ps1
or:
    python start.py

This automatically:
  1. Creates .env if missing
  2. Sets up the Python virtual environment (.venv)
  3. Installs Python dependencies (fastapi, uvicorn, etc.)
  4. Installs frontend dependencies (npm install)
  5. Starts the FastAPI backend (http://127.0.0.1:8000)
  6. Starts the Next.js frontend console (http://localhost:3000)
  7. Opens your browser automatically!

Press Ctrl+C at any time in the console to stop both servers cleanly.

========================================================================
MANUAL WAY (OPTIONAL / ADVANCED)
========================================================================

Terminal 1 (Backend):
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

Terminal 2 (Frontend):
    npm install
    npm run dev

Open:
    Frontend: http://localhost:3000
    Backend Docs: http://127.0.0.1:8000/docs
